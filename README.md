# 갈피 | GALPI

한국사·통합사회 학습과 수업 운영을 위한 정적 웹앱입니다.

- 통합사회 학습 모듈 5개 · 무역의 갈피 기본 학습 UX 개선
- 한국사2 대한민국 경제 변화 연구소 기본편·심화편 · 독립 진입과 주제별 연결
- 공통 학급 설정을 공유하는 조 나누기, 번호 추첨, 발표 순서, 타이머
- 기본 학급 인원 20명, 설정 펼침/접힘 상태 유지, 분·초 시간 자동 적용
- 학생 이름 입력 및 서버 저장 없이 브라우저 메모리에서 실행

`index.html`을 직접 열거나 정적 서버로 제공하면 실행됩니다. 새로고침하면 학습 활동과 수업 도구 설정·결과는 초기화됩니다. 최신 학습 구성과 자료 확인 범위는 `OCTOBER_14_README.md`를 참고하세요.

## GitHub Pages

저장소 Settings → Pages → Deploy from a branch → main / (root)를 선택합니다.
예상 공개 주소: https://yujin0117.github.io/galpi/

이 저장소에는 실행 파일과 사용 중인 브랜드 자산만 포함합니다. 백업과 검수 자료는 제외했습니다.

## 심화탐구 상담 관리 (간편 버전)

수업 도구의 **심화탐구 상담** 메뉴에 교사용 로컬 일정 편집기와 학생용 익명 예약 현황 달력을 추가합니다. 기존 구글 캘린더 예약을 유지하며 별도 서버·학생 회원가입·유료 백엔드 없이 운영합니다. 교사용 명단은 현재 브라우저에만 보관하고, 학생용 공개 자료는 개인정보 없는 `consultation-public.json` 파일로 별도 배포합니다. 교사용 수정 내역은 학생에게 자동 동기화되지 않습니다. 교사용 일정은 **PNG 이미지 다운로드**와 **A4 가로 PDF 인쇄/저장**을 지원하며, 두 출력은 브라우저에서만 처리하고 학생 실명을 포함하므로 외부 공유하면 안 됩니다. 학생용 공개 JSON v2에는 이름·반·학번·예약 인원을 넣지 않고 날짜·시간별 신청 가능/마감/완료만 공개합니다. 자세한 사용법과 백업 안내는 [CONSULTATION_SIMPLE.md](CONSULTATION_SIMPLE.md)를 확인하세요.
