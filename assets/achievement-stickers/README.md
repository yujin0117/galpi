# GALPI achievement stickers

Eight source-preserving RGBA cutouts from the user-approved sticker board (2026-10-29).
Included: 1-1, 1-2, 3-1, 3-2, 3-3, 5-1, 5-2, 5-3. Excluded: 1-3.

Original RGB pixels, aspect ratios, lettering and white die-cut borders are retained. Only the outer alpha mask and transparent padding were added. No generation, recoloring, sharpening or upscaling. Native sizes are approximately 378–424 pixels wide; result exports use at most 245 pixels. The source board and private QA files are not part of the site assets.
