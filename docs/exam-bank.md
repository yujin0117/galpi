## 구조

- `exam-data.js`: 원문 식별 정보, 학습 화면 자료, 고정된 5개 선택지, 공식 정답과 새로 작성한 해설. ID는 `연도-학년-월-번호`. 정답 인덱스는 0부터 시작한다.
- `exam-engine.js`: 필터·무작위 추출·선택·채점·최초 응답 보존·동일 문항 오답 복습. 기존 콘텐츠 계산 엔진과 독립적이다.
- `exam-practice.js`, `exam-practice.css`: 여러 콘텐츠에서 쓰는 공통 연습 UI. 기존 기초 연습을 감싸되 그 계산이나 데이터는 바꾸지 않는다.
- `assets/exams/`: 선택한 문항의 원문 이미지. 전체 문제지·해설지 PDF는 배포하지 않는다.

그림 자체가 자료인 7개 문항에는 PDF에서 직접 추출한 원본 시각자료 8개를 사용한다. `assets/exams/materials/`의 PNG는 그림을 다시 그리지 않고 4배 해상도로 렌더링한 것이다. `docs/exam-original-materials.json`에 문제지·페이지·추출 범위·크기·해시를 기록했다. 본문 이미지를 누르면 원본 확대 보기가 열리며 100~300% 확대, 화면 맞춤, Escape 닫기와 원래 위치 복귀를 지원한다. 복잡한 자료는 접근성을 위해 원문 내용의 텍스트도 접이식으로 제공한다.

기출 결과는 기출 풀이 화면 안에서 확인한다. 기존 기초 연습 결과와 합산하지 않는다. 새로고침 시 응답은 초기화되며 계정·영구 저장·외부 API를 사용하지 않는다.

## 추가 시 확인할 사항

1. 문제지 첫 페이지로 연도·학년·월을 확인하고 해설지와 짝을 맞춘다.
2. 현재 학습 범위 밖의 별도 지식이 필수인지 확인한다. 복합 문항은 필요한 개념 모두를 검토한다.
3. 원문 수치·조건·보기 순서·공식 정답을 유지한다. 표시 구조를 바꾼 경우 원문 이미지를 통해 대조할 수 있게 한다.
4. 요약, 단계별 풀이, 5개 선택지별 근거를 작성한다. 필요한 공식을 설명하고 원문 수치로 독립 검산한다.
5. 출처를 확인할 수 있는 원문 이미지를 추가한다. 숫자만 바꾼 변형을 공식 기출로 표시하지 않는다.
6. 회귀 검사 후 PC·모바일에서 문제와 해설을 실제로 연다. 유형 분류는 갈피의 학습용 분류이며 공식 정답률이 아니다.

## 회귀 검사

줄바꿈 보완(v1.3): 배점은 발문에서 분리해 출처 줄 오른쪽에 배치한다. 모바일 발문은 길이에 따라 14~17px, 선지는 13.5px로 표시하고 번호·좌우 여백을 줄여 문장의 가용 폭을 확보한다. 강제 한 줄, 말줄임, 내용 잘림을 적용하지 않으며 긴 문장은 자연스럽게 줄바꿈한다. 정답 표시 문구는 선지 본문 아래에 두어 답 공개 뒤에도 문장 폭을 유지한다.

2026-10-28 가독성 보완: 모바일 문제 본문은 14px(359px 이하 13.5px), 발문은 17px로 정리했다. 원문 30문항의 배점은 `points`, 밑줄 27곳의 범위는 `docs/exam-paper-annotations.json`에 기록한다. `node tests/exam-paper.cjs`로 원문 배점·밑줄 범위·보기 그룹을 확인한다. 배점은 원문 표시용이며 기존 결과의 최초 정답 수 집계는 바꾸지 않는다. 연도·학년·유형 필터와 정답·해설·선택지 순서도 유지한다.

저장소 루트에서 `node tests/exam-bank.cjs`를 실행한다. 공식 해설에서 확인한 고정 정답, 150개 선택지의 채점, 재도전과 최초 점수, 필터·중복 방지·오답 큐, 주요 계산을 검사한다. 원문 이미지·해설의 의미는 자동 검사만으로 검증되지 않으므로 원문 대조도 필요하다.

자료·선지 정렬 보완(v1.4): 원문에서 묶인 자료는 `ep-passage`의 얇은 직선 테두리로 구분한다. 보기 fieldset은 자료 박스 밖에 유지한다. 2026년 9월 고2 6번은 `choiceColumns`에 따른 (가)·(나)·(다) 열 머리글과 동일한 너비의 선택 행을 사용하며, 원래의 선택지 순서·값·채점은 유지한다. 각 선택 행은 하나의 키보드 접근 가능한 버튼이고 접근성 이름에 세 열의 연결을 모두 포함한다. 모바일 선지 간격은 0px, 행간 1.4, 최소 높이 40px로 정리한다.
